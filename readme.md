## Development Notes
The fundamental user interface design, base HTML structures, and core CSS styling were developed manually by the project members. To ensure cross-origin compatibility, modern JavaScript standards, and robust error handling during the highly complex integration of the asynchronous Fetch API with the backend, AI assistance was utilized for targeted guidance and logic refinement. The migration from session-based authentication (CSRF + cookies) to stateless JWT (Bearer tokens via localStorage) was implemented following the lab specifications for JWT authentication flow.
